**Why:** Conversation history is essential for continuity and context retention. `historyTrim: True` truncates history, breaking long-running workflows.

**How:**

```bash

}

# Find proxy config location (~/.claude/zunef-config.json or ~/.mekong-claude-wrapper/config.json)

  "historyTrim": false,
```
