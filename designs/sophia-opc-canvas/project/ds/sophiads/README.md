# Sophia Director Control Deck & `.v3-core` — Design System

Sophia AI Factory is a non-custodial One-Person Company (OPC) affiliate video production & governance platform for Crypto/CEX and Global SaaS offers.

## Visual Direction

- **Themes**: `Executive Studio Light` (`#f8f9fc` surface, `#4338ca` indigo, `#b45309` amber) and `Cinema Dark Room` (`#090a10` obsidian void, `#11131f` raised panel, `#6366f1` electric indigo, `#f59e0b` cinema amber).
- **Typography**: `Archivo` variable display (`wdth 104`) + `Be Vietnam Pro` for Vietnamese diacritics, `Plus Jakarta Sans` for body copy, and `JetBrains Mono` for telemetry eyebrows, SHA-256 digests, and ledger figures.
- **Anti-Slop Craft Rules**:
  - Never display fabricated user counts, fake star ratings, or unverified revenue claims.
  - Every dashboard KPI must trace to its underlying D1 data source and `DataTruthState` (`demo`, `not_connected`, `loading`, `error`, `verified_empty`, `live`).
  - Always distinguish `$0.00` AI script drafting from paid BYOK media rendering gated by CEO SHA-256 approval.
