   - PayOS is Vietnam domestic backup

   - Owner: Tech Lead

## Change Control Process

### Standard change

```
1. Propose → CEO + Tech Lead review
2. Implement → fullstack-developer
3. Test → npm test (all pass) + npm run build (exit 0)
4. Review → code-reviewer subagent
5. Approve → CEO sign-off
6. Deploy → npm run deploy:full + SHA verify + health check
7. Document → update changelog + this file
```

### Emergency change (production incident)

```
1. Assess → Tech Lead classifies severity
2. Fix → minimal, reversible change
3. Verify → build + tests + health check
4. Deploy → npm run deploy:full + SHA verify
5. Postmortem → within 24h, document in ops report
```

**Emergency changes may bypass review but MUST be documented within 24h.**

## Architecture Constraints (Non-Negotiable)

| Constraint | Rationale |
|---|---|
| 4-layer import direction: `seed → tree → forest → land` | Prevents circular dependencies; seed is foundational |
| Banned imports: `@/lib/auth`, `@/lib/subscription`, `@/lib/unified-tier-config`, `@/lib/tier-gate` | Post-consolidation cleanup; old paths deleted |
| Tier enum: `BASIC | PREMIUM | ENTERPRIUM | MASTER` (uppercase only) | Enforced by ESLint + tests |
| No `:any` types in production code | Repo standard |
| No `eslint-disable` additions | Suppression freeze |
| No `console.log` in production code | Use `@/seed/utils/logger-utility` |
| Inngest owns long-running workflows | Don't run these in request path |
| D1 is synchronous (no await on `createServerClient`) | D1 binding semantics |
| CF-direct deploy (GitHub Actions disabled by design) | Doctrine |

## Feature Gate Checklist

Before ANY new feature ships, all must pass:

- [ ] Tested (unit + integration)
- [ ] Build exits 0 with 0 TypeScript errors
- [ ] No `:any` types added
- [ ] No `eslint-disable` added
- [ ] Protected flows untouched (or documented deviation)
- [ ] Bilingual content (VN + EN) if customer-facing
- [ ] Banned imports not used
- [ ] Tier enum unchanged (or migration documented)
- [ ] Deployed with SHA verification
- [ ] Production health check passes
