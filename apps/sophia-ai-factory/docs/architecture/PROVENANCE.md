# Provenance Architecture

> **Layer**: tree  
> **Module**: `src/tree/provenance/`  
> **Database Table**: `provenance_records`  
> **Status**: Production-ready (Phase 1)

## Purpose

Provenance is an append-only audit trail for all generated and derived content. It answers:
- Who/what created this asset?
- What model/tool was used?
- What source material was it derived from?
- What human edits or approvals occurred?

## Data Model

```typescript
interface ProvenanceRecord {
  id: string;
  workspaceId: string;
  assetId: string;           // what was created/modified
  agentRunId?: string;       // which agent run produced it
  action: ProvenanceAction;  // created | generated | edited | approved | rejected | published | derived | archived
  actorType: 'human' | 'agent' | 'system';
  actorId: string;           // user ID, agent ID, or system ID
  model?: string;            // AI model used (gpt-4, claude-3-opus, etc.)
  modelVersion?: string;
  prompt?: string;           // prompt used (for AI generation)
  sourceAssetId?: string;    // parent asset if derived
  humanEdits?: string;       // JSON array of edit descriptions
  approvalId?: string;       // linked approval record
  derivativeOf?: string;     // explicit derivation reference
  metadata: Record<string, unknown>;
  createdAt: number;
}
```

## Chain of Custody

Every asset can reconstruct its full ancestry:

```
Asset: video_final.mp4
  ← derived from: video_draft.mp4 (ProvenanceRecord: "derived")
    ← generated by: AgentRun #42 (ProvenanceRecord: "generated")
      ← prompt: "Create SEA eco video..."
      ← model: gpt-4-vision
        ← source IP: "Eco Futures" universe (ProvenanceRecord: "created")
```

## API

| Function | Purpose |
|---|---|
| `recordProvenance(record)` | Append new provenance entry |
| `getProvenanceChain(assetId)` | Get all records for an asset (chronological) |
| `getDerivatives(assetId)` | Get all assets derived from this one |

## Guarantees

- **Append-only**: No updates or deletes (enforced by API design)
- **Immutable**: Once recorded, provenance entries cannot be modified
- **Complete**: Every asset must have at least one provenance record
- **Traceable**: Full chain from any asset back to original human/agent creation

## Integration

- **Tree → Land**: Billing can attribute costs to specific agent runs
- **Forest → Agent Protocol**: Every agent action records provenance
- **Tree → Creative Memory**: Provenance patterns inform memory updates
- **All layers**: Any created/derived asset must call `recordProvenance()`
