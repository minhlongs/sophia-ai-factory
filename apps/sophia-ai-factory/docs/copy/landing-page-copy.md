| **Action** | Two CTAs | "Start Free" beneath each card | "Start Free" CTA after step 3 | "Try free 7 days" CTA | "Start Free Trial" after Q5 |

### Emotional Triggers Used

1. **Achievement** ("kien $5k-$50k/thang" / "earning $5k-$50k/month")
2. **Control** ("tu Telegram" / "from Telegram" -- anywhere, any time)
3. **Safety** ("khong khoa vendor" / "no vendor lock-in" -- BYOK)
4. **Simplicity** ("3 buoc" / "3 steps" -- no complexity fear)
5. **Social Proof** ("CEO Viet Nam" / "Vietnamese CEOs" -- local relevance)
6. **Aspiration** (MASTER tier at $4,999 -- flagship positioning)

### Vietnamese Tone

Professional but warm. Uses "ban" (you -- friendly) throughout. Avoids overly formal "quy khach" which creates distance. Emojis are not included in this doc but should be added in the actual UI (the client is non-tech CEO, emojis improve clarity per handover rules).

### English Tone

Direct, benefit-first, confident. Short sentences. Active voice. Matches U.S. SaaS copy conventions (basecamp, stripe style) while keeping Vietnamese cultural references (Shopee, Lazada context).
