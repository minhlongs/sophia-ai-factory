## Interpretation

**Correctness:** ✅ Zero errors across 1630 total HTTP requests during both runs. CF Workers + D1 absorbed both load levels without 5xx.

**Latency:** ⚠️ p95 well above 500ms target across the board. Likely contributors:
1. **Geographic latency** — PT → CF nearest POP → upstream R2/D1 region adds 100-300ms baseline.
2. **OpenNext server-rendered home page** — SSR with first-paint workloads pulls ~1-2s.
3. **No edge caching** on most routes; only `/api/version` returns cache-control headers.
4. **Cold-start hit** for low-traffic endpoints.

## Recommended follow-ups
- Add Cache-Control: s-maxage=60 to public marketing pages (home, pricing, status).
- Pre-warm cold paths via cron ping every 5 min (existing `/api/health` cron would suffice if scaled to run more often).
- Consider Cloudflare Cache API + ISR for the homepage SSR output.
- Re-baseline with a closer client (run k6 from a Workers-region datacenter) to separate network jitter from app latency.
