⚠️ The Challenge / Thách Thức

A Fragmented Foundation

Before the redesign, Sophia AI Factory suffered from a scattered design identity — four competing MASTER.md files, a split between indigo-based Stitch tokens and amber-based CSS globals, and no reliable E2E infrastructure.

📂

4 Design Systems

Purple, pink, blue, and amber MASTER.md files — no single source of truth. Each Stitch session picked a different primary color.

🎨

Color Split

CSS globals used amber (#D97706) while Stitch tokens used indigo (#6366F1). Components rendered differently in dev vs. design.

🏗️

Build Failures

Static generation crashed on 11 routes because D1 bindings weren't available at build time. Deploy was blocked by prerender errors.

🧪

No E2E Infra

Playwright dev server took 5+ minutes to start. E2E tests were effectively unrunable locally. Auth and payment flows had no automated coverage.
