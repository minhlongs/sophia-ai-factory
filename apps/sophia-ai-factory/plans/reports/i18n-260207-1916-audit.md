# i18n Audit Report: Sophia AI Factory
**Date:** 2026-02-07
**Phase:** 4 - i18n

## 1. Current State
*   **Library**: `next-intl` is installed and configured.
*   **Structure**: `src/app/[locale]` pattern is in use.
*   **Messages**: `messages/en.json` and `messages/vi.json` exist but are minimal.
*   **Middleware**: Correctly configured to handle locale redirection.

## 2. Issues Identified
*   **Hardcoded Strings**: Widespread hardcoded strings found in `src/app/[locale]/dashboard/**`.
    *   Page titles and headings
    *   Button labels
    *   Form placeholders
    *   Table headers
    *   Status labels
*   **Incomplete Message Keys**: Existing message files cover basic dashboard stats and campaign creation, but lack coverage for:
    *   Analytics view
    *   System health
    *   Campaign list details
    *   Export controls

## 3. Remediation Plan
1.  **Update Message Files**: Add missing keys to `messages/en.json` (and `vi.json` as copy).
2.  **Refactor Components**: Replace hardcoded strings with `useTranslations` hook.
3.  **Verify**: Ensure keys match and rendering works in both locales.

## 4. Specific Targets
*   `src/app/[locale]/dashboard/layout.tsx` (Sidebar/Header)
*   `src/app/[locale]/dashboard/page.tsx` (Dashboard Home)
*   `src/app/[locale]/dashboard/campaigns/page.tsx` (Campaign List)
*   `src/app/[locale]/dashboard/create/page.tsx` (Create Wizard)
*   `src/app/[locale]/dashboard/analytics/page.tsx` (Analytics)
*   `src/app/[locale]/dashboard/system-health/page.tsx` (Health)
