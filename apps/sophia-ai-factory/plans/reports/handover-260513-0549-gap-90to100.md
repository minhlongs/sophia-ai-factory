## 5. Things That Will Trip Up Next Session

1. **CF-direct doctrine** — `git push` does NOT deploy. Production is updated ONLY via `npm run deploy:full`. GH Actions `.disabled` files in `.github/workflows/` are intentional.

3. **SHA verify is non-negotiable** — `curl /api/version | jq .shortSha` must match `git rev-parse HEAD | cut -c1-8` after every deploy. HTTP 200 alone proves liveness but NOT freshness (CF cache can serve stale worker).
