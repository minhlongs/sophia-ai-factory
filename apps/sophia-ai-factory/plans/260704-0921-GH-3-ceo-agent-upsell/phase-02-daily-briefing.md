# Phase 2: Daily Briefing

## Overview
Adds the `/dashboard/ceo-agent/briefing` child route with a once-per-day personalized morning briefing generated by the existing `forest/agents/daily-briefing/briefing-generator`.

## Context Links
- Parent route: `src/app/[locale]/dashboard/ceo-agent/page.tsx`
- Leaf card: `src/forest/components/agents/daily-briefing-card.tsx`
- Generator: `src/forest/agents/daily-briefing/briefing-generator.ts`

## Architecture
- Server page → `loadCeoAgentPage` (single auth/tier source) + `generateDailyBriefing(userId, locale)` → hydrates `BriefingClient`.
- Manual refresh bound to a Server Action (`refreshBriefingAction` with `useTransition`).
- No new D1 tables; memory adapter for once-per-day cache is reused.
- Error path renders bilingual empty state with retry button.
- 4-layer compliant: landing page (land segment) imports forest/land types, server action is also in `land/.../briefing/actions.ts`.
