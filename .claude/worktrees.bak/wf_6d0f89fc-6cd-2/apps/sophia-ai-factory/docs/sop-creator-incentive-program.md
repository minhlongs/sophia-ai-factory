# SOP Creator Incentive Program (70/30 Revenue Share)

Generated: 2026-06-02 | Owner: CEO / Head of Product

---

## 1. Purpose

Reward external SOP creators who publish high-quality, verified SOP templates on the Sophia Marketplace. 70% of recurring subscription revenue attributable to a creator's SOP flows to the creator; 30% is retained by Sophia as platform margin.

---

## 2. Eligibility

| Requirement | Detail |
|---|---|
| KYC / W-8BEN (or local equivalent) | Required before first payout |
| SOPs must pass QA review | ≥ 4-star avg rating, < 5% refund rate |
| Active for ≥ 60 days | No new creator exit in month 1 |
| No conflict of interest | Creator cannot be a Sophia employee/contractor |

---

## 3. Revenue Attribution Model

- **Primary attribution:** `sop_id` stored on every subscription at checkout (UTM param `?sop_id=<id>` or explicit selection in checkout).
- **Recurring:** Attribution persists for 12 months from sign-up (or until user upgrades to a tier that does not include SOPs).
- **Multi-touch:** If a user references multiple SOPs, split is pro-rata by install count.

---

## 4. Payout Terms

| Parameter | Value |
|---|---|
| Creator share | **70%** of net attributable MRR |
| Platform share | **30%** (covers infra, billing, support) |
| Payout frequency | Monthly, in arrears (30-day lag) |
| Minimum payout | $50 |
| Method | Stripe Connect / wire (configured at KYC) |
| Accounting line item | `Cost of Revenue — SOP Creator Payouts` |

## 5. Dashboard (Creator View)

Each SOP creator sees:

- `sop_earnings` summary (MTD, QTD, YTD)
- Per-SOP breakdown (installs, MRR attributed, earnings)
- Payout history (date, amount, method, status)
- Tax docs (W-9 / W-8BEN form upload)

Planned route: `/dashboard/sop-creator/[id]/earnings` (UI to be built by Product).

## 6. Fraud / Quality Guardrails

| Risk | Mitigation |
|---|---|
| SOP stuffing / copy-paste | QA review + similarity detection (cosine ≥ 0.92 triggers manual review) |
| Fake installs | Rate-limit by `license_nonce` + IP; flag > 10 installs/24h from same IP |
| Self-referral | Block creator's own email/org from triggering payout |
| Churn gaming | Attribution window caps at 12 months; high-churn SOPs get de-ranked |
