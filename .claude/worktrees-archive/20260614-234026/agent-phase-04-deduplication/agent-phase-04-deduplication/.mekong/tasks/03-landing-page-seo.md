# Mission 03: Landing Page + SEO Content

**Priority:** P1 — HIGH
**Stage:** Zero → PSF
**Layer:** Business (Marketing)
**Target:** Organic traffic acquisition
**MCU Budget:** 20

## Objective

Create compelling landing page with SEO-optimized content to attract
Vietnamese SMBs searching for "tạo video AI" and related keywords.

## Steps

1. Audit current landing page (sophia.agencyos.network)
2. Add Vietnamese SEO content: hero, features, pricing, testimonials
3. Create 5 blog posts targeting keywords:
   - "tạo video AI tự động"
   - "phần mềm làm video marketing"
   - "HeyGen Vietnam tutorial"
   - "AI video cho doanh nghiệp"
   - "so sánh công cụ tạo video AI 2026"
4. Set up Google Search Console + sitemap
5. Add Open Graph + Twitter card meta tags

## Success Criteria

- [ ] Landing page loads < 2s (LCP)
- [ ] Vietnamese content on all pages
- [ ] 5 blog posts published
- [ ] Google Search Console verified
- [ ] First organic visitor within 30 days

- **CMO:** Content strategy + blog writing
- **CTO:** Technical SEO + meta tags
