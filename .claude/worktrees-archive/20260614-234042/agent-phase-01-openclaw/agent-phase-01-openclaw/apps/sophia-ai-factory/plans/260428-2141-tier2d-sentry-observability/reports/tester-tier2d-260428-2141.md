## Key Fixes Applied

### Issue #1: Sentry Release Fallback (buildEdgeOptions test)
**Root Cause:** Module-level constants evaluated at import time; `process.env.COMMIT_SHA ?? process.env.SENTRY_RELEASE` treated empty string `''` as truthy value, preventing fallback.

**Fix:** Converted to lazy getter functions with explicit null/undefined checks:
```typescript
const getRelease = () => {
  const commitSha = process.env.COMMIT_SHA?.trim();
  if (commitSha) return commitSha;
  const sentryRelease = process.env.SENTRY_RELEASE?.trim();
  if (sentryRelease) return sentryRelease;
  return 'local';
};
```

**Files Modified:**
- `src/lib/observability/sentry-options.ts` (lines 10-18)

**Impact:** Allows tests to stub env vars per-test without module-level interference. No behavioral change in production.
