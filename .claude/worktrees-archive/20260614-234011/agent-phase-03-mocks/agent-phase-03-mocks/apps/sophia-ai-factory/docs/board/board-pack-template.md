## How to Use This Template

Each month, the CEO (or delegate) fills in actuals vs. plan using D1 data.
The board pack is assembled automatically via `/api/admin/board-pack` and
delivered asynchronously to board members via email (or downloaded from admin).

**Distribution:** Board members + investors (Series A+) access via `/dashboard/admin/board`.

## Board Meeting Cadence

| Frequency | Format | Participants |
|---|---|---|
| Monthly (async) | Board pack + written comments | All board members |
| Quarterly (sync) | 60-min video call + Q&A | All board members + CEO |
| Ad-hoc | As needed for major decisions | Relevant parties |

**Async board process:**
1. CEO distributes board pack by 5th business day of month
2. Board members review and add comments within 5 business days
3. CEO consolidates comments and sends resolution summary
4. Decisions recorded in board minutes ([board-minutes.md](./board-minutes.md))
