# Design Guidelines — Sophia AI Factory

This document outlines the visual identity and layout patterns for the Sophia AI Factory platform.

## Visual Theme & Palette
* **Theme:** Dark Futuristic / High-tech cyberpunk aesthetic.
* **Background:** Deep Slate `#020617` / Midnight Black `#000000`.
* **Primary Accent (Neon Cyan):** `var(--neon-cyan)` / `#00f0ff` (used for active indicators, neon glows, and primary borders).
* **Secondary Accent (Violet):** `#8b5cf6` (used for admin-only modules and subtle gradient shifts).
* **Gradients:** Cyan-to-violet linear gradients for premium banners and visual CTA assets.

## Typography
* **Primary Sans:** Inter (Google Fonts) for standard UI elements and text.
* **Secondary Display:** Outfit (Google Fonts) for display metrics, dashboard greeting, and headlines.
* **Font Sizes:**
  * Title Display: 32px / 2rem (`font-bold`)
  * Section Headers: 20px / 1.25rem (`font-semibold`)
  * Body Text: 14px / 0.875rem (`text-sm`)

## Components & Layout
* **Sidebar:** Glassmorphism overlay (border: `white/5`, background: `slate-950/40`, backdrop-blur).
* **Borders:** Thin slate borders (`slate-800` or `white/5`) with neon glow transition states on hover (`shadow-[0_0_12px_rgba(0,240,255,0.15)]`).
