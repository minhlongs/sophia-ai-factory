## Sending checklist (per partner)

- [ ] Personalize `{{first_name}}` + `{{specific_context}}` (or `{{referrer_name}}` for Template B)
- [ ] Verify `FREE100` code still valid: visit `/pricing` in incognito, try the code (don't redeem)
- [ ] Send from `{{founder}}@mekongmind.com` (NOT a generic email — improves deliverability)
- [ ] Log to tracker: `docs/handover/free100-distribution-tracker-260512.md`
- [ ] If reply requested: set 24h follow-up reminder

---

## DO NOT do

- ❌ Mass-send via Mailchimp/SendGrid blast — kills inbox placement. Send 1-by-1 via Gmail/Outlook personal.
- ❌ Add tracking pixels — Resend tracking is already off (transactional hygiene).
- ❌ Use shortlinks (bit.ly, etc.) — looks like spam.
- ❌ All caps in subject lines.
- ❌ Include the magic link itself in the outreach email — partners must self-trigger via /pricing flow.
- ❌ Promise specific features that aren't shipped yet.
