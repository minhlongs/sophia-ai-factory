# V-1.1 IDOR Fix Report

**Date:** 2026-05-22
**Severity:** CVSS 9.1 (any authenticated user could drive any tenant's campaign)

## Root Cause

`retryCampaign` and `resumeCampaign` fetched campaign by `id` only — no caller identity check.
A session from User B could pass `campaignId` of User A and mutate + requeue it.

## Fix

Added `getCurrentUser()` call at top of both functions (before DB fetch).
After fetching campaign, asserts `c.user_id === currentUser.id`.
Returns `{ success: false, message: "Unauthorized" }` on mismatch or null session.

Import path: `@/seed/auth/better-auth-session` (canonical per dev-rules).
