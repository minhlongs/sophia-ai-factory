**Strengths:**
- HSTS max-age=63072000 with `preload` — excellent
- All security headers present (X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy)

## Priority Gaps

### CRITICAL
1. **GH Actions blocked** — deploy CI (`Tests & Deploy`) cannot trigger. Direct `wrangler deploy` is current path. Risk: no automated test gate before production deploy. **Fix:** Unblock GH Actions at user level OR document manual pre-deploy test checklist enforced via git hook.
2. **`continue-on-error: true` on Lint + Test** in `Tests & Deploy` — broken tests won't block deploy. **Fix:** Remove `continue-on-error` from both steps; failures must be hard blocks.

### HIGH
3. **No Sentry SDK** — `SENTRY_DSN` in docs but zero `@sentry/nextjs` code. Stack traces unreadable. **Fix:** `npm install @sentry/nextjs`, add `sentry.client.config.ts` + `sentry.server.config.ts`, upload source maps in deploy step.
4. **No source maps** — minified CF Workers bundle means all stack traces are useless. **Fix:** Configure `--source-map` in opennext build; upload to Sentry or Better Stack.
5. **Static asset browser cache TTL=0** — hashed assets should be immutable. **Fix:** Add `/_next/static/:path*` header block in `next.config.ts` with `Cache-Control: public, max-age=31536000, immutable`.
6. **No CAA records** — **Fix:** `dig CAA agencyos.network` should return `letsencrypt.org` or `pki.goog`. Add via CF DNS: `0 issue "pki.goog"` (Google Trust Services).
7. **No SPF record** — **Fix:** Add `v=spf1 include:_spf.google.com ~all` (or appropriate sender) to `agencyos.network` TXT.
8. **D1 backup artifact-only** — **Fix:** Add step to `d1-backup.yml` to upload to R2: `wrangler r2 object put sophia-backups/d1-backup-${DATE}.sql --file backup-${DATE}.sql`.

### MEDIUM
9. **DMARC `p=none`** — **Fix:** Change to `p=quarantine` after validating SPF/DKIM alignment. Prevents email spoofing.
10. **`ignoreBuildErrors: true`** — masks ~462 TS errors. **Fix:** Schedule TS cleanup sprint; remove flag after.
11. **`script-src 'unsafe-inline'` in CSP** — **Fix:** Use nonces (Next.js nonce support) or move inline scripts to external files.
12. **No PR preview deployments** — **Fix:** Use CF Workers `--env preview` in a `pull_request` deploy step.
