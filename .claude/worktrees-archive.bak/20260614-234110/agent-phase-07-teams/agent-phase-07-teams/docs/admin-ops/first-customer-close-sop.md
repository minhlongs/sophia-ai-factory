# Sophia First-Customer Close SOP

Last updated: 2026-05-13

Goal: close and activate the first paying Sophia customer without losing operational evidence.

## Pre-Demo

1. Confirm the prospect use case, target language, desired video style, and publishing channel.
2. Pick the recommended plan:
   - Starter/BASIC: simple pilot.
   - Growth/PREMIUM: weekly production.
   - Premium/ENTERPRISE: automation/API need.
   - Master: white-label/source-code handover.
3. Prepare one demo prompt and one proof video.
4. Confirm checkout method: NOWPayments or PayOS.

## Demo Call

1. Show prompt to script to video flow.
2. Show dashboard usage and billing status.
3. Explain provider-key model and what Sophia stores.
4. Confirm SLA and support channel.
5. Ask for plan selection and payment method.

## Close

1. Send checkout link.
2. Verify payment in NOWPayments or PayOS.
3. Confirm account activation in Sophia.
4. Send onboarding message with:
   - Login URL
   - Selected plan
   - Provider key setup steps
   - Support channel
   - First video workflow

## First 7 Days

| Day | Action | Owner | Evidence |
|---|---|---|---|
| 0 | Confirm payment and account activation | Operations | |
| 1 | Customer creates first video | Support | |
| 2 | Review video quality and provider errors | Engineering | |
| 3 | Confirm publishing/download workflow | Support | |
| 5 | Ask for feedback and blocker list | Founder/operator | |
| 7 | Renewal/expansion check and testimonial ask | Founder/operator | |

## Close Criteria

- Paid plan active.
- Customer generated at least one usable video.
- Support ticket channel has a customer record.
- Any blockers are logged with owner and due date.
