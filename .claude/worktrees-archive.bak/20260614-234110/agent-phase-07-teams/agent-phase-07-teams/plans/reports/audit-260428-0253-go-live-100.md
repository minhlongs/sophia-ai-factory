## 🔴 CRITICAL BLOCKERS (must fix before declaring 100/100)

### B1. CI/CD test gate effectively bypassed
- **Where:** `.github/workflows/test.yml` — `Lint` and `Test` steps both have `continue-on-error: true`
- **Impact:** Broken tests/lint do NOT block deploy. Combined with GH Actions user-level block on `longtho638-jpg`, the only deploy path is direct `wrangler deploy` with **no automated quality gate**.
- **Fix:** (a) Remove `continue-on-error` from both steps. (b) Unblock GH Actions at user level OR document a mandatory pre-deploy CLI gate (`npm run build && npm test && npm run lint` → required green before `wrangler deploy`).
- **Effort:** 1h (workflow edit) + user-level GH unblock action.

### B2. 462 TypeScript errors masked
- **Where:** `apps/sophia-ai-factory/next.config.ts:24` `typescript.ignoreBuildErrors: true`
- **Impact:** Build is not a type-safety gate. Type drift accumulating silently. Violates Sophia rule "Zero `:any` types — use proper TypeScript interfaces".
- **Fix:** Schedule TS cleanup sprint. Fix in batches per route domain. Then flip the flag.
- **Effort:** 2 sprints (462 errors @ ~3-5min/error) — biggest single ticket.

### B3. Three admin-auth schemes coexist + 4 unauthenticated state-changing endpoints
- **Where (admin):** `checkAdminAuth()` Basic Auth | `x-admin-key` | JWT Bearer fallback
- **Where (public mutating):** `coupons/apply`, `errors/report`, `setup/save`, `realtime/alerts`
- **Impact:** Admin-bypass / IDOR / log-injection / credential-leak vectors. `coupons/apply` allows anonymous redemption of FREE50 (100% discount).
- **Fix:** (a) Single `requireAdmin(request)` helper using Better Auth session + `users.role='admin'`. Delete `ADMIN_USER/ADMIN_PASS/ADMIN_API_KEY` paths. (b) Auth-gate the four public endpoints, add per-user redemption count for coupons. (c) Add MFA via Better Auth two-factor plugin.
- **Effort:** 3-5 days.

### B4. Frontend i18n catastrophic in videos route (1/10)
- **Where:** `src/app/[locale]/dashboard/videos/**` (9 files, 35+ raw English strings)
- **Impact:** Vietnamese users see 100% English on the flagship video flow. Mirror problem: `dashboard/error.tsx` is Vietnamese-only — EN users see Vietnamese errors. Sophia handover rule: "all docs must be simple, bilingual".
- **Fix:** Add `dashboard.videos` namespace in `messages/en.json` + `messages/vi.json`. Wrap all 9 files (server pages with `getTranslations`, clients with `useTranslations`). Localize `dashboard/error.tsx`. Fix 4 hardcoded `/login` redirects to use `localizedHref`.
- **Effort:** ~6h single session.

## 🟡 HIGH GAPS (close to reach 90+/100)

3. **Nonce-based CSP**: drop `script-src 'unsafe-inline'`, emit per-request nonce.
