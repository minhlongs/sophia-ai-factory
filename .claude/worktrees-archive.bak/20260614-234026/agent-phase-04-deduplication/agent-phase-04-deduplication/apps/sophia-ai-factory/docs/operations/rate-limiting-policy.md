## 1. Rate Limit Tiers

| Tier | Requests / min | Burst | Scope | Enforcement |

## 2. Enforcement Stack

1. **Cloudflare WAF** — IP + geo rate limits at edge (broad catch).
2. **KV counter** — Per-key sliding window (60s) via KV atomic increment + TTL.
3. **Middleware** — `RateLimiter` in `src/middleware.ts` rejects with `429` + `Retry-After`.
4. **Quota checker** — `quota-checker.ts` enforces monthly caps (per tier).

## 3. KV Key Schema

```
ratelimit:{apiKeyId}:{windowStart}
  → integer (increment)
  TTL: 90s
```

## 4. Responses

- **Under limit:** `200 OK` + `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`.
- **Over limit:** `429 Too Many Requests` + `Retry-After: <seconds>` + JSON body `{ error: "rate_limited", retryAfter }`.
- **No API key:** `401 Unauthorized`.

## 5. Monitoring

- KV atomic op latency p50/p95 (alert if p95 > 50ms).
- 429 count per endpoint per minute (exposed via `/api/admin/metrics`).
- Alert: > 10% of requests returning 429 on a 5-min window.
