# Bootstrap OPC Loop

Name: bootstrap-loop

## Goal

Turn a project objective into executable OPC tasks.

## Steps

- [ ] Set the project goal with opc goal --set
- [ ] Write the first plan checklist with opc plan --set
- [ ] Configure build/test gates with opc config set
- [ ] Seed backlog with opc task seed
- [ ] Run opc loop --once or open opc tui
