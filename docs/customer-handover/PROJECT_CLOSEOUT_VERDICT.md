### 4.2 Known Edge Technical Notice & Remediation Record

For complete transparency and non-repudiation, the following isolated edge notice is formally documented:

- **Surface**: `/api/sophia-index/health` (Returns HTTP 500 on live edge).
- **Classification**: Isolated Non-Critical Notice (Zero impact on core video generation, studio onboarding, billing, or playbooks).
- **Root Cause Analysis**:  
  Code inspection of `src/land/supabase/sophia-index.ts:101-104` reveals an invocation of `db.from('affiliate_categories').select('*')`. Table `affiliate_categories` belonged to legacy Supabase PostgreSQL migrations (`supabase/migrations/001_create_sophia_index.sql`) and was not included in the 239 Cloudflare D1 SQLite migrations (`migrations/0001-0239`). D1 SQLite throws `no such table: affiliate_categories`.
- **Impact Assessment**:  
  This route is an auxiliary affiliate directory endpoint. It has zero interaction with the core Creative Mission pipeline, Setup Wizard, BYOK vault, or Payment IPN webhooks.
- **Remediation Roadmap**:  
  Documented in `DAY_1_ACCEPTANCE_TEST_REPORT.md §7`. The incoming engineering team can either apply migration `0275_affiliate_categories.sql` to D1 or update `getCategories()` to return a graceful empty array fallback `[]`.
