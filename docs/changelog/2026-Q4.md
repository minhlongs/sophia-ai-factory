## [2026-10-08] Social Direct Publisher & OAuth Cockpit (v1.48.0)

**Summary (vi):** Hoàn thành hệ thống phân phối đa kênh trực tiếp (Social Direct Publisher) và buồng lái quản trị OAuth (OAuth Cockpit) hỗ trợ xuất bản video tự động lên TikTok Content Posting API v2, YouTube Shorts Resumable API, và Instagram Reels Graph API. Triển khai vault mã hóa Web Crypto API RFC 5869 HKDF-SHA256 kết hợp AES-256-GCM với AAD binding ngữ cảnh kênh (`src/seed/security/oauth-token-vault.ts`). Lưu trữ thông tin xác thực trên D1 SQLite có khóa kiểm soát đồng thời lạc quan (OCC) chống xung đột refresh token đa luồng và tự động phục hồi khóa sau 5 phút (`src/land/social/platform-credentials-store.ts`). Bộ điều phối nhịp điệu đăng bài chống phát hiện (anti-detection pacing engine) áp dụng thời gian chờ 180 phút giữa các bài đăng cùng kênh, hạn mức ngày (YouTube: 6, TikTok: 4, IG: 4), và độ trễ ngẫu nhiên đồng đều jitter 45–90 phút (`src/tree/social/publisher/pacing-engine.ts`). Quy trình chạy ngầm qua Inngest bền vững với circuit breaker tự ngắt khi token bị thu hồi (`src/forest/inngest/functions/social-direct-publish-job.ts`), Server Actions xác thực người dùng (`src/forest/actions/social-publisher-actions.ts`), và giao diện buồng lái Obsidian Cyber-Glass (`src/components/social-publisher/` & `/dashboard/social-publisher`) tích hợp trình phát tỷ lệ 9:16 có lưới an toàn cho từng nền tảng, bảng điều khiển trạng thái kết nối và kill-switch khẩn cấp. Toàn bộ 44/44 unit test Vitest vượt qua, không lỗi TypeScript, tuân thủ nghiêm ngặt kiến trúc 4 tầng Clean Architecture.

**Summary (en):** Shipped the Social Direct Publisher & OAuth Cockpit (v1.48.0) supporting automated direct video publishing to TikTok Content Posting API v2, YouTube Shorts Resumable API, and Instagram Reels Graph API. Implemented zero-dependency Web Crypto RFC 5869 HKDF-SHA256 key derivation with AES-256-GCM authenticated encryption and context-bound AAD (`src/seed/security/oauth-token-vault.ts`). Delivered D1-backed credential storage with Optimistic Concurrency Control (OCC) locking to prevent concurrent token refresh race conditions and 5-min stale lock recovery (`src/land/social/platform-credentials-store.ts`). Engineered anti-detection pacing engine enforcing 180-min channel cooldowns, platform daily caps (YouTube: 6, TikTok: 4, IG: 4), and organic uniform jitter delays (45–90 min) (`src/tree/social/publisher/pacing-engine.ts`). Built durable multi-step Inngest publishing job with fail-closed circuit breaker protection on revoked tokens (`src/forest/inngest/functions/social-direct-publish-job.ts`), authenticated Server Actions (`src/forest/actions/social-publisher-actions.ts`), and Obsidian Cyber-Glass cockpit UI (`src/components/social-publisher/` & `/dashboard/social-publisher`) with 9:16 vertical safe-zone preview player, real-time token expiry countdown telemetry, and emergency kill switches. 44/44 Vitest tests passing across 6 suites, zero TypeScript errors, strict 4-layer architecture compliance.

**Key Architecture Deliverables:**
- **Web Crypto HKDF Token Vault (`src/seed/security/oauth-token-vault.ts`):** Edge-native RFC 5869 HKDF-SHA256 key derivation with AES-256-GCM authenticated encryption bound to `social-vault:${userId}:${platform}:${channelId}` context.
- **Platform Chunking & Protocol Adapters (`src/tree/social/publisher/platform-adapters.ts`):** Chunk slicing calculations for YouTube 256 KiB aligned resumable uploads, TikTok v2 multi-chunk uploads (5MB-64MB) with status polling, and Instagram Reels Cloudflare R2 container publishing.
- **Anti-Detection Pacing Engine (`src/tree/social/publisher/pacing-engine.ts`):** 180-min channel cooldown, daily caps, and uniform random jitter delay (45–90 min).
- **D1 OCC Locking Stores (`src/land/social/platform-credentials-store.ts`, `publish-job-store.ts`):** Atomic token refresh locking with 5-min stale lock recovery, emergency kill switches, and job lifecycle persistence.
- **Durable Inngest Workflow (`src/forest/inngest/functions/social-direct-publish-job.ts`) & Server Actions (`src/forest/actions/social-publisher-actions.ts`):** 5-step publish orchestration with authenticated Server Actions.
- **Obsidian Cyber-Glass Cockpit UI (`src/components/social-publisher/` & `src/app/(app)/dashboard/social-publisher/page.tsx`):** 9:16 vertical safe-zone preview overlay (TikTok, Shorts, Reels guides), channel credentials grid with live token countdown, and bilingual VN/EN copy.
- **Quality Gates:** 44/44 unit tests passing, zero `:any` types, zero layer boundary violations, all files <200 LOC.
