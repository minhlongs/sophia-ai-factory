## 1. Executive Summary

Sophia AI Factory is a **no-code, no-tech Revenue-as-a-Service (RaaS) platform** that enables non-technical CEOs to build and scale automated affiliate marketing empires using AI-generated video content.

Customers bring their own API keys (BYOK) for AI services (OpenRouter, ElevenLabs, D-ID, HeyGen) and configure everything via a Setup Wizard — no developer needed. The platform handles video generation, campaign management, Telegram bot operations, billing, and affiliate payouts.

**Tagline:** Create. Automate. Earn. No code required.

---

## 2. Product Description

### 2.1 Creator Marketplace
A two-sided marketplace where video creatoRs list SOPs (Standard Operating Procedures) and customers purchase automated video campaigns. Built-in rating, review, and discovery.

### 2.2 Growth Infrastructure
- **Telegram Bot (@Sophia_Bbot):** /campaign, /status, /results commands. Real-time campaign management from any device.
- **Affiliate Network:** Built-in affiliate tracking with commission management, payouts, and referral codes.
- **Multi-provider AI Video:** HeyGen, D-ID, FaceFusion, Wav2Lip — automatic fallback if one provider fails.
- **Setup Wizard:** Guided onboarding for API keys (OpenRouter, ElevenLabs, D-ID, HeyGen, NOWPayments).

### 2.3 Agency Bundles
White-label agency bundles for digital agencies to resell AI video services to their clients. Includes custom branding, sub-account management, and bulk pricing.

### 2.4 AI Quality & Reliability
- Automatic multi-provider fallback for video generation
- Built-in reconciliation to detect revenue leakage (orphan purchases)
- D1 database with R2 lifecycle backup (30-day retention)
- Sentry error capture + Cloudflare Worker logs
