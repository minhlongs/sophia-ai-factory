Sophia AI Factory is a no-code, no-tech Revenue-as-a-Service (RaaS) platform for AI video generation and affiliate marketing automation. We serve non-technical CEOs and creators across Southeast Asia.

**Stack:** Next.js 16 (App Router), TypeScript, React 19, Tailwind CSS, Cloudflare Workers (OpenNext), D1 (SQLite), R2, Sentry, Inngest

**Scale:** 6,700+ tests, 30K+ lines of TypeScript, CI-free CF-direct deployment, 99.9% uptime

## Role Overview

You will be the second engineering hire, working alongside the founder to build and scale the platform. You will own feature development from design to deployment, maintain infrastructure, review code, and help shape the engineering culture.

This is a high-leverage role — you will ship code that thousands of paying customers rely on for their businesses.

---

## Responsibilities

- **Feature Development:** Build and ship customer-facing features across the full stack — backend (Cloudflare Workers, D1), frontend (Next.js, React, Tailwind), and orchestration (Inngest)
- **Infrastructure:** Maintain and improve the Cloudflare Workers deployment pipeline, D1 database performance, R2 cache strategy, and monitoring stack (Sentry, Worker logs)
- **Code Review:** Review pull requests for correctness, performance, security, and adherence to the 4-layer architecture (seed, tree, forest, land)
- **Testing:** Maintain and expand the test suite (Vitest, Playwright E2E). Enforce quality gates: 0 TypeScript errors, 0 `:any` types, 0 `console.log` in production code
- **Documentation:** Contribute to technical docs, API references, and operational runbooks
- **Performance:** Profile and optimize D1 query performance, Cloudflare Worker CPU/memory usage, and frontend bundle size
