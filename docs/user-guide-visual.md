## 3. Thiet Lap / Setup Wizard

**URL:** `/setup-wizard`

### Ban se thay gi tren man hinh / What you will see on screen

Man hinh cai dat co **4 buoc**. Ban chi can lam **1 lan duy nhat**.
Setup screen with **4 steps**. You only need to do this **once**.

| Phan / Section | Mo ta / Description |
|---|---|
| **Header** (tim) | Tieu de "Sophia Setup Wizard" + mo ta ngan / Title + short description |
| **Thanh tien trinh / Stepper** | 4 buoc: System > AI Keys > Database > Finish / 4 steps shown as progress bar |
| **Noi dung / Content area** | Thay doi theo buoc hien tai / Changes based on current step |
| **Nut dieu huong / Footer buttons** | "Back" + "Next Step" hoac "Launch Sophia" / Navigation buttons |

#### Buoc 1: Kiem Tra He Thong / Step 1: System Check

- Sophia tu dong kiem tra he thong / Sophia automatically checks your system
- Ban thay dau tich xanh (OK) hoac do (loi) / You see green check (OK) or red (error)
- **Khong can lam gi** — chi nhan "Next Step" khi thay xanh / Just click "Next Step" when green

#### Buoc 2: Nhap API Keys / Step 2: AI Keys

Nhap 3 "chia khoa" de ket noi dich vu AI / Enter 3 "keys" to connect AI services:

| Truong / Field | Dich vu / Service | Chuc nang / Purpose |
|---|---|---|
| **OpenRouter API Key** | openrouter.ai | Viet kich ban AI / AI script writing |
| **ElevenLabs API Key** | elevenlabs.io | Tao giong noi / Voice generation |
| **D-ID API Key** | d-id.com | Tao avatar video / Avatar video creation |

- Dan key vao o > nhan "Verify" > thay dau xanh = OK / Paste key > click "Verify" > green = OK
- Khi ca 3 xanh, nhan **"Next Step"** / When all 3 are green, click "Next Step"

#### Buoc 3: Co So Du Lieu / Step 3: Database (Airtable)

- Nhap **Airtable Personal Access Token** / Enter your Airtable token
- Nhap **Base ID** / Enter Base ID
- Nhan "Verify" de kiem tra / Click "Verify" to check

#### Buoc 4: Hoan Thanh / Step 4: Finish

- Xac nhan tat ca da thiet lap thanh cong / Confirms all setup is complete
- Nhan **"Launch Sophia"** (nut xanh la) / Click the green button

### Ban can lam gi / What you need to do

- Chuan bi 3 API keys truoc (xem huong dan trong app) / Prepare 3 API keys beforehand
- Nhap tung key, verify tung cai / Enter and verify each key
- Nhan "Next Step" qua tung buoc / Click through each step

### Sau khi bam > chuyen gi xay ra / After clicking > what happens

- "Launch Sophia" > Chuyen den Dashboard / Goes to Dashboard
- Neu loi: se hien thong bao va cho tai file .env.local / On error: shows message + downloads config file
